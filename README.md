# Finger Photo to Model

Проект для автоматического построения параметрической 3D-модели пальца
(протеза/муляжа фаланг) по обычной фотографии кисти руки. Программа
находит на снимке ключевые точки руки, вычисляет реальные размеры
фаланг выбранного пальца и сохраняет их в конфигурационный файл, по
которому затем в AutoCAD или КОМПАС-3D строится параметрическая
3D-модель пальца с подвижными суставами.

## Как это работает (пайплайн)

1. **Фото → ключевые точки руки.** `measure_by_img.py` через
   [MediaPipe Hands](https://google.github.io/mediapipe/solutions/hands.html)
   находит 21 ключевую точку кисти на изображении (`hand.jpg` — тестовое
   фото).
2. **Ключевые точки → длины фаланг.** Для каждого пальца (большой,
   указательный, средний, безымянный, мизинец) по расстояниям между
   соседними суставами считаются длины проксимальной, средней и
   дистальной фаланг — сначала в относительных координатах кадра, затем
   переводятся в миллиметры с помощью калибровочного коэффициента.
3. **GUI для измерения и настройки.** `app.py` — desktop-приложение на
   `tkinter`: загружает фото, показывает изображение с наложенным
   скелетом руки (landmarks) и таблицу измерений по всем пальцам,
   позволяет выбрать конкретный палец и задать дополнительные
   параметры модели — радиусы фаланг, радиус сустава, углы сгиба между
   фалангами.
4. **Сохранение конфигурации.** По кнопке «Сохранить конфигурацию»
   создаётся текстовый файл вида `<палец>_finger_config.txt`
   (пример — `index_finger_config.txt`) с набором параметров:
   ```
   L1=46.36...   # длина проксимальной фаланги, мм
   L2=27.55...   # длина средней фаланги, мм
   L3=20.44...   # длина дистальной фаланги, мм
   R1=10.0       # радиус проксимальной фаланги
   R2=10.0       # радиус средней фаланги
   R3=10.0       # радиус дистальной фаланги
   R_joint=15.0  # радиус сустава
   FlexAngle1=10.0  # угол сгиба между 1-й и 2-й фалангами
   FlexAngle2=10.0  # угол сгиба между 2-й и 3-й фалангами
   ```
5. **Конфигурация → 3D-модель.** Файл конфигурации читается одним из
   CAD-скриптов, который строит по нему 3D-тело пальца:
   - `finger_autocad.lsp` — LISP-скрипт для AutoCAD (команда
     `create_finger_model`): читает параметры из файла, строит
     цилиндры фаланг, сферические суставы и переходные элементы между
     фалангами через булевы операции (`_intersect`, `_subtract`),
     учитывая заданные углы сгиба.
   - `finger_compass.cs` — эквивалентный скрипт на C# для API
     КОМПАС-3D (`FingerModelCreator`, `ParametersLoader`): через COM
     (`KompasObject`) создаёт тот же параметрический набор тел —
     цилиндры фаланг, смещённые и повёрнутые плоскости для суставов,
     сферы на кончиках пальца.

## Структура репозитория

| Файл | Назначение |
|---|---|
| `app.py` | GUI-приложение (tkinter) — точка входа, объединяет измерение и сохранение конфигурации |
| `measure_by_img.py` | Логика распознавания руки (MediaPipe), расчёт длин фаланг и генерация конфиг-файла |
| `hand.jpg` | Тестовая фотография руки для проверки распознавания |
| `index_finger_config.txt` | Пример готового конфигурационного файла (указательный палец) |
| `finger_autocad.lsp` | Скрипт построения 3D-модели пальца в AutoCAD |
| `finger_compass.cs` | Скрипт построения 3D-модели пальца в КОМПАС-3D (C#, COM API) |

## Технологии

- **Python** — `opencv-python`, `mediapipe`, `Pillow`, `tkinter`
- **AutoCAD LISP (AutoLISP)** — параметрическое построение геометрии
- **C# + COM API КОМПАС-3D** (`Kompas6API5`, `Kompas6Constants3D`) —
  альтернативная реализация построения модели

## Запуск

```bash
pip install opencv-python mediapipe pillow
python app.py
```

В открывшемся окне: «Загрузить изображение» → фото с распознанным
скелетом руки и таблица измерений по всем пальцам → выбрать палец и
задать радиусы/углы → «Сохранить конфигурацию». Полученный
`*_finger_config.txt` передаётся в `finger_autocad.lsp` (команда
`create_finger_model` в AutoCAD) либо используется как вход для
`finger_compass.cs` в КОМПАС-3D.

## Область применения и ограничения

Проект задумывался как прототип инструмента для быстрого получения
индивидуальных параметров пальца (например, для 3D-печати протезов
или ортопедических муляжей) без ручных измерений штангенциркулем —
достаточно одной фотографии кисти. Это учебный/исследовательский
прототип:

- калибровочный коэффициент перевода в миллиметры (226) подобран под
  условия съёмки тестового фото и требует калибровки под реальную
  камеру/дистанцию;
- обработка большого пальца — частный случай (иная геометрия суставов
  относительно остальных четырёх пальцев);
- CAD-скрипты рассчитаны на построение модели одного пальца за
  запуск.
